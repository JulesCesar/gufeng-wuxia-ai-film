# 古装武侠 AI 短片生产方法

一套从真实项目里长出来的 AI 短片工作方法，不是理论。

**来源**：《武松·行者》51 镜实战 —— 一镜抽了 5 版、一镜抽了 4 版，每一次失败都换成一条纪律。

**方法论层参考**：Higgsfield 开源的那部 95 分钟 AI 长片（HELL GRIND）生产管线的五条铁律，以及 acting / CINEDANCE 文档。

---

## 这份东西解决什么

用 Seedance / 可灵 / LibTV / 即梦 做古装或武侠短片时，反复遇到的六件事：

1. **50 镜剪起来一冷一热** —— 画风锁
2. **同一角色三张脸** —— 素材台账 + 挂图纪律
3. **某镜反复出不来** —— 五条铁律（尤其是「拆镜头不要加词」）
4. **画面发塑料、发绿、背景死黑** —— 画风锁的七段拆解
5. **加了一堆禁止词反而更错** —— 负面词的「分配而非禁止」
6. **人物表情像硅胶** —— 给眼睛一个任务

## 三条最值钱的

**① 拆镜头，不要加词**

一镜抽到第三版还不对，先问：这是「描述不够」还是「动作太复杂」？
描述不够 → 加一句；动作太复杂 → **拆镜**。

**② 负面词要过测试**

每写一个负面词，只问一句：**模型的默认行为本来就是那个错吗？**
是 → 可以禁；不是 → 禁这个词等于把选项递给它。

**③ 摄影机是情绪的影子**

运镜不该由「够不够电影」决定，该由人物的情绪决定。
平静的场景配抖动手持、愤怒的场景配平滑推轨——**动作对，但镜头是无感的**。
