# 一镜提示词样例

三种类型各一份完整样例，可直接改。

---

## 样例 A · 空镜（图生视频）

**用途**：佛像、器物、建筑，画面里没有人，只有极轻的动态。

```
基础多模态生成，4 秒，16:9。
画风锁：中国古装武侠电影的写实影像，宋代。整体气质苍凉、沉郁、厚重。
色彩：以青绿灰、墨绿青、炭黑为主色，土褐只用于木案、石阶与器物；整体饱和度克制，保留肌肤的棕褐与微弱血色；环境和阴影轻微偏青绿，受光部位是湿的白与冷的灰、不是暖金——全场没有任何暖色光源，唯一的暖色只允许出现在佛像的旧金与器物上；冷暖分离清晰。
光照：低调，只用侧光、不用侧逆光（不许给人镶金边），大面积深色阴影，人物面部有自然的明暗分区；黑位深沉但保留衣物、头发和建筑的层次；亮部平滑过渡，窗光与日光有光源亮度、周围材质仍能辨认；近景厚重清晰，远景随距离降低对比度。
空气：香火的烟极薄，只在光里可见。
材质：人物皮肤保留毛孔、细纹、汗水、尘土与轻微瑕疵；衣物呈粗布、麻布质感，有磨损和褶皱；建筑呈现风化木纹、斑驳墙面和湿润石材，金属表面有氧化与使用痕迹；反光随材质变化，整体粗粝、真实。
镜头：35 毫米电影摄影的观感，人物镜头用自然透视与适度浅景深、环境仍可辨认；全景保留空间纵深；细微胶片颗粒，细节清晰且锐度自然，运动时保留合理的运动模糊；16:9 横画幅。
一致：与全片其他镜头使用同一套底色、材质与色温；肤色与衣物颜色跨镜稳定。

@图1 是**首帧**：完整继承它的构图、取景、机位、光位与色彩——五尊佛的纵深排列、最近那尊在画面右侧、密铺方格天花在顶部。画面第一帧必须与原图完全一致，**不裁切、不放大、不重新构图**。

一句话：殿内极暗，五尊佛沿纵深排开，一道冷光落在最近那尊的膝上。

【画面必须有这四层，缺一不可】
① 前景（画面下方约三分之一）：铺着旧白布的供桌，桌面上有铜香炉、花瓶、供品、两只烛台。这张桌子是佛像尺度的参照——**桌面的高度只到佛像的膝盖**。它必须一直在画面里。
② 中景：五尊佛沿纵深排列，最近那尊在画面右侧；多层雕饰的须弥座；胁侍菩萨立在佛与佛之间。
③ 背景：密铺方格天花压顶，深褐的梁架与圆柱。
④ 左侧：一道冷光从高窗斜切下来，穿过空气，落到最近那尊的膝上。

动态：**只有供桌上那只铜香炉的香火，升起一丝极薄的烟**——烟几乎是透明的，只在左侧那道光里露出一线轮廓，其余看不见；上升极慢，没有边界，不成股。
**镜头静止机位，一帧都不推、不拉、不摇。**
除此以外完全静止：佛不动、光不动、供桌不动。**没有人物入画。**

取景锁定：全程景别、构图、机位与原图完全一致；**不得推近、不得拉远、不得裁切、不得重新构图**。

音频（**只用环境音，不许有任何音乐**）：
**必须有**：极轻的空气声，一声远处的木鱼（很弱）。
**必须没有**：配乐、背景音乐、旋律、节拍、鼓点、和声、乐器、人声哼唱。
这段声音是**这处空间本来就有的声音**，不是配乐。检测到音乐就是错的。

避免：鲜艳糖果色、通体碧绿色偏色、肤色发青、粉紫色调、均匀正面补光、脸部美颜磨皮、蜡质皮肤、塑料衣物、崭新洁净的古装、游戏建模质感、卡通渲染、过度锐化、全局泛光、暗部完全死黑、亮部大面积过曝、跨镜头色温和饱和度跳变。
禁止：**丢掉供桌、丢掉香炉**、四尊等大的中像、明亮均匀的光、崭新的大红大金、现代灯具、游客、浓烟、烟柱、干冰、舞台烟雾、雾变浓。
```

**模式：图生视频 ／ 4s**

## 样例 B · 有人（全能参考 + 台词）

**用途**：人物入画、有动作、有台词。台词是同期声。

```
基础多模态生成，5 秒，16:9。
画风锁：中国古装武侠电影的写实影像，宋代。整体气质苍凉、沉郁、厚重。
色彩：以青绿灰、墨绿青、炭黑为主色，土褐只用于木案、土地与器物；整体饱和度克制，保留肌肤的棕褐与微弱血色；环境和阴影轻微偏青绿，受光部位呈柔和暖金或琥珀色，冷暖分离清晰，暖色只集中在人物受光边缘与实际光源附近。
光照：低调，明确的侧光或侧逆光，大面积深色阴影，人物面部有自然的明暗分区；黑位深沉但保留衣物、头发和建筑的层次；亮部平滑过渡，窗光、灯火、日光有光源亮度、周围材质仍能辨认；近景厚重清晰，远景随距离降低对比度。
空气：浮尘与油气，被门口的光切出一条。
材质：人物皮肤保留毛孔、细纹、汗水、尘土与轻微瑕疵；衣物呈粗布、麻布质感，有磨损和褶皱；建筑呈现风化木纹、斑驳墙面和湿润石材，金属表面有氧化与使用痕迹；反光随材质变化，整体粗粝、真实。
镜头：35 毫米电影摄影的观感，人物镜头用自然透视与适度浅景深、环境仍可辨认；全景保留空间纵深；细微胶片颗粒，细节清晰且锐度自然，运动时保留合理的运动模糊；16:9 横画幅。
一致：与全片其他镜头使用同一套底色、材质与色温；肤色与衣物颜色跨镜稳定。

@图1 是**空间与光参考**：完整继承这间酒肆的空间、陈设与光位（右侧门口一道光柱进来、桌面一块亮斑、墙上木牌、左侧酒瓮、泥土地面）；**不继承它的空景状态**，允许加入人物。
@图2 是**人物参考**：完整继承五十岁不到的瘦削脸、乱发短须、**袒胸的麻布短褐**、胸口的刺青；**不继承**白底与影棚光。

一句话：酒肆里，一个店家站在桌边陪着笑，一个高个子坐在桌后。

【画面必须有这四层，缺一不可】
① 前景（画面下方）：粗陶碗与木桌面，一只碗搁在桌沿。
② 主体：店家站在桌子右侧、离桌半步，微微躬身，一只手在围裙上擦；**主角坐在桌后，只露肩以上，背对门口，脸在暗里**。
③ 背景：右侧敞开的门口，外面是亮的天光；左侧几只酒瓮；墙上一块木牌（**不许有字**）。
④ 光：门口那道光柱斜进来，落到桌面一块；主角的脸在暗里，只一侧有微光。

动作：中景，固定机位。店家陪着笑说话；主角不动，只在最后抬了一下眼。
**镜头静止机位，不推、不摇。**

【表演】
- 店家的眼睛：看着对方的眼睛，在判断这句话说没说进去；目光一直在动。
- 店家的呼吸：急促一点，肩膀随说话起伏。
- 主角：脸在暗里，只有眼睛动——**眼睛从碗上移到店家脸上，很慢**。
- 主角的呼吸：几乎没有起伏，很平。

音频（**只用环境音，不许有任何音乐**）：
**必须有**：碗筷轻响、远处街市的环境声。
**必须有**：店家（画面右侧那个躬身陪笑的男子，中年男声，压着嗓子，带笑意）开口说话——**他本人发出的声音，声画同步**：嘴与下颌随字句动作，声音从画面内那个位置来，音色与这个人相符。不是画外有人念：「客官，三碗不过冈。冈上有大虫，白日里也出来。」
**必须没有**：配乐、背景音乐、旋律、节拍、鼓点、和声、乐器、人声哼唱、以及画外音、旁白、解说、后期配音。
环境音是**这处空间本来就有的声音**；台词是**画面里那个人自己发出的声音**。检测到音乐、或听到画外有人在念，都是错的。

避免：鲜艳糖果色、通体碧绿色偏色、肤色发青、粉紫色调、均匀正面补光、脸部美颜磨皮、蜡质皮肤、塑料衣物、崭新洁净的古装、游戏建模质感、卡通渲染、过度锐化、全局泛光、暗部完全死黑、亮部大面积过曝、跨镜头色温和饱和度跳变。
禁止：现代物件、游客、明亮均匀的光、多余人物、木牌上出现文字、暖色铺满画面。
```

**模式：全能参考 ／ 5s**

## 样例 C · 静镜 + 极缓动作（图生视频，无台词）

**用途**：只有一个动作的静镜（抬手、呼吸、叶子落）。

```
基础多模态生成，8 秒，16:9。
画风锁：中国古装武侠电影的写实影像，宋代。整体气质苍凉、沉郁、厚重。
色彩：以青绿灰、墨绿青、炭黑为主色，土褐只用于木案、石阶与器物；整体饱和度克制，保留肌肤的棕褐与微弱血色；环境和阴影轻微偏青绿，受光部位是湿的白与冷的灰、不是暖金——全场没有任何暖色光源，唯一的暖色只允许出现在佛像的旧金与器物上；冷暖分离清晰。
光照：低调，只用侧光、不用侧逆光（不许给人镶金边），大面积深色阴影，人物面部有自然的明暗分区；黑位深沉但保留衣物、头发和建筑的层次；亮部平滑过渡，窗光与日光有光源亮度、周围材质仍能辨认；近景厚重清晰，远景随距离降低对比度。
空气：清晨薄雾贴地，近处厚、远处淡。
材质：人物皮肤保留毛孔、细纹、汗水、尘土与轻微瑕疵；衣物呈粗布、麻布质感，有磨损和褶皱；建筑呈现风化木纹、斑驳墙面和湿润石材，金属表面有氧化与使用痕迹；反光随材质变化，整体粗粝、真实。
镜头：35 毫米电影摄影的观感，人物镜头用自然透视与适度浅景深、环境仍可辨认；全景保留空间纵深；细微胶片颗粒，细节清晰且锐度自然，运动时保留合理的运动模糊；16:9 横画幅。
一致：与全片其他镜头使用同一套底色、材质与色温；肤色与衣物颜色跨镜稳定。

@图1 是**首帧**：完整继承它的构图、取景、机位、光位与色彩——他盘腿坐在台基石沿上、面朝画面左侧、**右手搭在膝上**、左袖空着、竹帚横在脚边。画面第一帧必须与原图完全一致，**不裁切、不放大、不重新构图**。**这张参考图身上没有叶子**——第一帧必须是空的，叶子在后面才落。

一句话：他把右手抬到胸前立掌、闭眼；一片叶子飘落在他身上，他不拂。

【画面必须有这五层，缺一不可】
① 前景（画面下方）：台基的石沿、石阶的边缘；**横放在脚边的竹帚**。
② 主体（中部偏右）：他盘腿坐在台基面上，占画面高度约三分之二；面朝画面左侧；**右手搭在右膝上（首帧就搭着，不是已竖掌）**；左袖空着掖在腰带里；僧袍浅灰；颈下挂一串木念珠。
③ 背景：大殿的台基侧壁、两根圆形朱漆柱、殿门那片纯黑。
④ 光与空气：清晨冷光从左侧（院子方向）来，照亮他的正面与柱的一侧；画面左侧是院子，有薄雾。
⑤ **竹帚**：横放在他脚边的石板上，帚头朝右，**全程不动**。

【叶子 · 写死】
一片**最普通的枯树叶**：**简单的椭圆形，边缘微卷**，轮廓规整，**没有裂片、没有尖角、没有锯齿**。
暗褐色，接近土色；叶脉清楚但整体很素，不显眼。
**约拇指指甲大小**，在画面里只占一点点——**不能比他的耳朵大**。

动作（按时间）：
0–2.5 秒，**右手从膝上慢慢抬起来**——小臂向上、手掌立起，抬到胸口高度，**手指并拢**（竖掌）；
2.5–4 秒，手停在胸前稳住，**眼睛闭上**；
4–7 秒，**一片枯叶从画面右上角极缓地飘进来**，打着转往下落，落在**他身上**——衣襟上、膝上、或右袖上都可以，**位置不必精确，自然就好**；
7 秒，落定，只被风带着极轻地颤一下。
7–8 秒，**他不动，也不拂**——眼睛仍闭着。

【关键】
**只有右手动。** 左手不存在（左袖空着）。
抬手很慢，像做了几十年、不着急。**叶子落在哪不重要，落在身上就行。**
**镜头全程固定，不跟叶子、不推、不摇。** 焦点始终在他的脸上；叶子飘进来时在焦外，落定后才略微清楚。

取景锁定：全程景别、构图、机位与原图完全一致；**不得推近、不得拉远、不得裁切、不得重新构图**。

音频（**只用环境音，不许有任何音乐**）：
**必须有**：极轻的风，一段无风似的静。
**必须没有**：配乐、背景音乐、旋律、节拍、鼓点、和声、乐器、人声哼唱。
这段声音是**这处空间本来就有的声音**，不是配乐。检测到音乐就是错的。

避免：鲜艳糖果色、通体碧绿色偏色、肤色发青、粉紫色调、均匀正面补光、脸部美颜磨皮、蜡质皮肤、塑料衣物、崭新洁净的古装、游戏建模质感、卡通渲染、过度锐化、全局泛光、暗部完全死黑、亮部大面积过曝、跨镜头色温和饱和度跳变。
禁止：两只手、合十、左手出现、朝镜头、朝画面右侧、**僵硬如雕塑、面无表情的端坐**、笑、暖光、佛像入画、**叶子过大、叶子形状复杂带裂片、颜色鲜艳、多片叶子飘落、镜头跟拍叶子、叶子特写**。
```

**模式：图生视频 ／ 8s**

## 三份样例的对比

| | A 空镜 | B 有人 | C 静镜+动作 |
|---|---|---|---|
| 模式 | 图生视频 | 全能参考 | 图生视频 |
| 时长 | 4s | 5s | 8s |
| 动作数 | 0（只有烟） | 2（说话 + 抬眼） | 3（抬手 → 闭眼 → 叶落） |
| 台词 | 无 | 有 | 无 |
| 画风锁 | C 型 | A 型 | C 型 |
| 特殊 | 层清单四层 | 表演段 | 叶子写死形状尺寸 |

**C 的 8 秒是特例**：抬手要 2.5 秒、停 1.5 秒、叶落 3 秒。

**判断时长够不够**：把每个动作的最短时间加起来，再看余量。低于合计就是赶。
