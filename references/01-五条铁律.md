# 五条铁律

来自 Higgsfield 那部 95 分钟 AI 长片（HELL GRIND）的开源生产管线。每条都是因为"没有它，某镜就失败了"才写下的。

---

## 1. Assets first — 素材先行

**不要生成任何一镜，直到每个角色、场景、道具都锁定并压力测试过。**

这一条省下的钱，比其余所有加起来都多。

### 什么叫"压力测试"

不是"图看着顺眼"，是**拿它去生成一镜，看会不会崩**：

| 素材 | 怎么压测 | 通过标准 |
|---|---|---|
| 人物定妆照 | 生成一镜他做某个动作 | 脸不变、衣服不换、比例不歪 |
| 场景图 | 生成一镜有人物在里面的画面 | 空间关系不错、光位一致 |
| 道具图 | 生成一镜手持它 | 形制不走样、比例对 |

**没过压测的素材不要进生产。**

### 反面案例

一部片子的人物定妆照出了三版，第三版才"看着对"。直接拿去生成，结果：

```
第 1 镜  脸对
第 2 镜  脸瘦了一圈
第 3 镜  眉毛没了
第 4 镜  换成了另一个人
```

**问题不在后续镜，在第一镜没压测**——如果先拿定妆照生成一镜"他抬头"，就会发现脸会飘，那时候改定妆照还来得及。

## 2. Describe everything, every time — 每次都完整描述

**视频模型没有记忆。** 上一镜生成过什么，它完全不知道。

所以：**描述要进每一镜，一字不省。**

### 具体做法

一镜一镜复制同一段画风锁、同一段人物描述、同一段场景描述。

```
❌ 第 1 镜写全，第 2 镜写「同上」
❌ 第 1 镜写「浅灰僧袍」，第 2 镜写「僧袍」
✅ 每一镜都写「浅灰粗麻僧袍，有磨损与褶皱，左袖空着掖在腰带里」
```

### 为什么不能省

省掉的每一个词，模型都会自己补一个——**补的那个和别人不一样**。

真实后果：一镜写了"青灰僧袍"，另一镜写"僧袍"，剪起来是两件不同颜色的衣服。

### 唯一的例外

如果贴了参考图，人物描述可以缩短——**但前提是那个参考图本身足够描述这个人物**。且这条在业界有争议（一套管线说可以缩，另一套说不行）。保险做法：**图照贴，描述照写**。

## 3. Change one thing at a time — 一次只改一样

**整段重写，会连改对的一起丢掉。**

### 做法

```
v1  原稿                    → 失败：构图被裁
v2  v1 + 首帧声明改成「完整继承」  → 构图对了，但烟太多
v3  v2 + 烟改成「光柱里的空气」    → 通过了
```

每一版只改一处，**并且记进失败档案**。

### 为什么

如果 v2 一次改了五处，通过了——**你不知道是哪一处起的作用**，下次遇到同样问题还是不会。

### 日志格式

```
│ 镜 │ 版本 │ 改了什么（一句话）           │ 结果 │
│ T00b │ v1 │ 原稿                        │ 只拍到膝盖 │
│ T00b │ v2 │ 挂载声明改「完整继承构图」    │ 构图对，烟成团 │
│ T00b │ v3 │ 烟改成「光柱穿过的空气」      │ 雾太厚 │
│ T00b │ v4 │ 加「不要把雾加厚」           │ 通过 │
```

## 4. Less freedom — 少给自由

**给角落，不给房间。给锚点，不给空地。一镜一个动作。**

### 三组对照

| 给多了 | 给少了 |
|---|---|
| "他在一个房间里" | "他坐在台基石沿上，占画面高度三分之二，面朝画面左侧" |
| "桌上有碗" | "桌上排着十七只粗陶空碗，散排、彼此靠近、三四只倒扣" |
| "他在扫地，然后坐下，然后喘" | "他坐着喘" |

### 一镜一个动作

4 秒里塞四个动作（停下 → 放帚 → 坐下 → 喘），每件 1 秒，**必然每一件都做不好**。

砍成"只坐着喘"之后一次过。

**过程可以交给剪辑补**——观众看到上一镜站着、下一镜坐着，中间那两秒自己会补。**不用拍出来的事，就不拍。**

### 时空锚点

给模型一个明确的地理位置，比给它一整片空地可靠：

```
❌ 站在院子里
✅ 站在台基下面的院子地面上——脚下不是台基顶面、不在石阶上、不在廊下；
   台基在他身后偏右，顶面略高于他的腰
```

## 5. Simplify the shot, not the words — 拆镜头，不要加词

**这是最容易被违反的一条，因为人的本能反应是"再加一句约束"。**

### 判断标准

**一镜抽到第三版还不对，问自己：这是"描述不够"，还是"动作太复杂"？**

```
描述不够   → 加一句（比如"扫帚下端必须是散开的竹枝"）
动作太复杂 → 拆镜（比如"扫地"拆成"手握柄特写"+"帚头扫过石板"）
```

### 真实案例：扫地五版

```
v1  只写「一把磨秃的竹帚」          → 画成一根光溜溜的竹管
v2  加「下端是散开的竹枝扎成的帚头」  → 画对了，但握在柄顶端、站到了台基上
v3  加「站在台基下面」「正手握柄」    → 手上去了，胳膊伸直像在戳地
v4  加「手腕下沉、肘微弯」           → 扫帚斜倒，像在拖地
v5  全写死                          → 通过，但提示词成了全片最长的一条
```

**按第 5 条铁律，v3 就该拆镜：**

```
镜头 A  手在柄上的特写（一动作：握）
镜头 B  帚头扫过石板（一动作：扫）
```

两镜各一动作，比继续加词便宜得多，而且 A 镜根本不用画全身。

### 什么时候该拆

| 症状 | 该拆吗 |
|---|---|
| 手部动作反复做不对 | ✅ 拆：手部特写 + 动作中景 |
| 全身动作（坐下、起身）做不对 | ✅ 拆：只拍结果，过程交给剪辑 |
| 多人互动做不对 | ✅ 拆：单人镜各拍，靠剪辑对 |
| 画面元素少了 | ❌ 不拆，加层清单 |
| 构图被裁 | ❌ 不拆，改首帧声明 |

## 附：管线的四条底层原则

除了五条铁律，那份开源文档里还有四句值得抄下来：

```
① 每一个规则之所以存在，都是因为某一镜在没有它的时候失败了。
② 这个管线不需要十五个人 —— 它需要规则被遵守。它能缩到一个人。
③ 如果一镜合不上：拆成两半、减掉一个动作、换个角度。
④ 把每一次生成都记进日志，包括成功的。
```

**第 4 条尤其重要**——只记失败的日志，算不出"平均几版能过"，也就没法估成本。
