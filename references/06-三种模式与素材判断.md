# 三种生成模式与素材判断

## 一、模式三分

| 模式 | 参考图是什么 | 适合什么 | 首帧 |
|---|---|---|---|
| **图生视频** | **首帧**——第一帧就是成片 | 静镜、空镜、只呼吸不动的镜 | 必须有，且只有 1 张 |
| **全能参考** | 素材——只借内容，不继承构图 | 人物动作、新构图、参考图里没有的状态 | 不是首帧 |
| **文生视频** | 无 | 没有对应素材的场景、纯氛围镜 | 无 |

## 二、判断口诀

```
「和这张图一模一样，只是动起来」      → 图生视频
「用这张图的人/这间屋子，重新构图」    → 全能参考
「这张图里没有的东西」                → 文生视频
```

## 三、最容易错的四种情况

### ① 给空景图，却要拍桌上的东西

```
✗ 图生视频 + 酒肆空景图 → 要拍"桌上十七只碗"
  结果：给你一间空屋子，桌上什么都没有
```

**图生视频的第一帧就是空景，AI 不会在上面"加"东西。**

改法：**全能参考**，借空间与光，碗靠文字生成。

```
@图1 **只借空间与光**：继承这张木桌的材质与尺寸、墙上的木牌、左侧的酒瓮、
右侧门口进来那道光斑的位置。
**不继承「空桌」这个状态**——这一镜的桌面上必须摆着碗。
```

### ② 给人物定妆照，却要拍他做动作

```
✗ 图生视频 + 站姿定妆照 → 要拍"他坐下"
  结果：他站着，或者摆出一个不像坐下的姿势
```

**图生视频会把首帧的姿势锁死。**

改法：**全能参考**，只借人物长相与服装。

### ③ 给三视图，却当首帧用

```
✗ 图生视频 + 三视图 → 要拍一个具体画面
  结果：画面里出现三视图的排版
```

**三视图是"形制参考"，不是画面。** 只能当全能参考的素材。

### ④ 没有任何图，却要求精确构图

```
✗ 文生视频，写"他站在画面左侧三分之一处，面朝右"
  结果：位置、朝向、比例全靠运气
```

文生没有锚点，**精确构图必须靠图**。

## 四、挂图数量规则

| 模式 | 图的数量 | 说明 |
|---|---|---|
| 图生视频 | **必须正好 1 张** | 多了 AI 不知道哪张是首帧 |
| 全能参考 | 1–3 张 | 空间 + 人物 + 色彩参考，每张写明"借什么" |
| 文生视频 | **0 张** | 挂了图就不是文生了 |

### 每张图都要写"借什么、不借什么"

```
@图1 是**空间与光参考**：继承台基石沿、石阶、柱子与殿门的黑、清晨薄雾与左侧冷光。

@图2 是**人物参考**：继承剃发、浅灰僧袍、左袖空着、木念珠。**不继承它的站姿与背景。**

@图3 是**色彩参考**：只借它的黄绿色关系，不借它的构图与内容。
```

**没写"不借什么"，AI 会把参考图里的一切都搬过来**——包括背景、姿势、光位。

## 五、色彩参考的用法与误用

**色彩参考图只借色彩关系，不借场景。**

### 正确用法

一部片子有一个"色彩基准场景"（比如某个有阳光穿过树叶的庭院），把它当色彩参考，贴给**同类光线的户外镜头**。

```
适用：山上、街市、有草木的户外
不适用：阴天的战场、水边、室内
```

### 误用（真实案例）

一部片子把"寺院庭院的黄绿版"当色彩参考，贴给了六镜：

```
街市（有树）   → ✅ 合理
水边芦苇    阴天，水边   → ✗ 不是庭院的黄绿
土坡战场    天阴烟尘     → ✗
山脊远景    灰天剪影     → ✗
断臂镜头    烟尘扬起     → ✗
自割镜头    特写         → ✗
跪地镜头    天阴         → ✗
```

**挂错色彩参考，比不挂更糟**——它会把庭院的绿带进战场。

### 判断标准

```
这张色彩参考图的"光线条件"和这一镜一样吗？
晴天透光树叶的黄绿 ≠ 阴天战场的灰白
```

## 六、没有素材的场景怎么办

**三个办法，按优先级：**

### ① 串起来：先用文字生成第一镜，截它的帧当后续镜的参考

```
第 1 镜  文生视频（场景靠文字）
第 2 镜起  用第 1 镜的一帧当空间参考（全能参考）
```

**先做的那一镜就成了这个场景的"定稿"。**

### ② 写一段统一的场景描述，逐镜照抄

```
【场景统一，与其他战场镜头同一处】
睦州城外的土坡：黄土与碎石，草很少、被踩平；天阴，灰白的天，没有太阳；
远处有未散的烟，贴着地面走。画面里没有绿树、没有青翠的草木——
这里的颜色是土褐、灰、炭黑，青绿只出现在暗部，不出现在环境里。
```

**这段要在每一镜里都写**，一字不省。

### ③ 补一张场景定稿图

最稳，但多一轮出图。

**如果这个场景有 3 镜以上，值得出图；只有 1 镜，用办法 ②。**

## 七、检查表

```
□ 每镜的模式，和素材数量匹配吗？（图生 1 / 全能 1-3 / 文生 0）
□ 每张参考图，都写了"借什么、不借什么"吗？
□ 图生视频的镜，首帧图里有没有"这一镜要拍的东西"？
□ 色彩参考图的光线条件，和这一镜一样吗？
□ 没有素材的场景，用办法①②③了吗？
```
