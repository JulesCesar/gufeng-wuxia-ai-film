# 失败档案

真实镜头的失败与修复记录。**每一条都是抽了真金白银换来的。**

---

## 档案一：殿内五尊 · 抽了 4 版

### 要拍什么

殿内极暗，五尊佛由近到远排开，前景有供桌，左侧一道冷光。

### 四版的错

| 版本 | 错在哪 | 原因 |
|---|---|---|
| v1 | **只拍到了一尊佛的膝盖和莲座** | 挂载声明写了「不继承构图」 |
| v2 | 构图对了，但**烟像干冰喷出来**，一整片白 | 写了"香火的烟"，但画面里没有香炉 |
| v3 | 构图又偏了，**左半幅全是雾** | 加了一句"不要把雾加厚"，反而激活了雾 |
| v4 | ✅ 通过 | 首帧锁 + 四层清单 + 烟有源 |

### 关键认知

**"不继承构图"这六个字，让 AI 自由取景了。** 它把五尊佛裁成了一尊的膝盖。

**提"烟"却不提"香炉"，AI 只能自己造一个源**——它造了一整片雾。

## 档案二：菩萨垂目 · 抽了 2 版

### 要拍什么

脸占画面三分之二，只有左半边被照亮，其余在暗里。佛像完全不动。

### 两版的错

| 版本 | 错在哪 | 原因 |
|---|---|---|
| v1 | ✅ 基本可用 | — |
| v2 | **构图推近了 15–20%，宝冠被推出画外** | 写了「镜头极缓推进 3%」 |

### 关键认知

**AI 分不清"极缓"和"推"。** 写 3%，它推 15–20%。

**要推，后期做。** 提示词里一律写"静止机位"。

## 档案三：一片落叶 · 抽了 2 版

### 要拍什么

一片枯叶从上方落下，停在台基前的石板上。地上已经有几片旧叶。

### 两版的错

| 版本 | 错在哪 | 原因 |
|---|---|---|
| v1 | **地上太干净**，只有落下的那一片 | 没写"地上已有的旧叶" |
| v2 | ✅ 通过 | 加了"地上有五六片旧叶，暗、旧、完全不动" |

### 关键认知

**"扫地"这个语境下的地面，不该是干净的。**

但也不能写成"满地落叶"——那就变成秋天美景，不是"他正在扫的那片地"。

**准确说法**：`地上已经有五六片落在那儿的枯叶，零散分布，不聚堆，更暗更旧`。

### 附带问题：模式选错

原来用**文生视频**，结果背景给了一片随机森林。

改**全能参考**（挂空间图，只借地面），背景才锁住。

**文生没有锚点，背景一定跑偏。**

## 档案四：扫地 · 抽了 5 版

### 要拍什么

他站在台基前的院子里扫落叶，右手握竹帚，左袖空着。

### 五版的错

| 版本 | 错在哪 | 原因 |
|---|---|---|
| v1 | **扫帚变成一根光溜溜的竹管** | 只写"一把磨秃的竹帚"，没写形状 |
| v2 | 扫帚对了，但**握在柄的顶端**、**站到了台基上** | 没写握法；参考图里他坐在台基上 |
| v3 | 手上去了，但**胳膊伸直像在戳地** | 没写"肘微弯" |
| v4 | **扫帚斜倒，像在拖地** | 加了"手腕下沉"，AI 理解成"放低扫帚" |
| v5 | ✅ 通过 | 全部写死 |

### 关键认知

**这一镜该拆，不该加词。**

按第 5 条铁律，v3 就该拆成：

```
镜头 A  手在柄上的特写（一动作：握）
镜头 B  帚头扫过石板（一动作：扫）
```

**加词到最后，提示词成了全片最长的一条**——而那是失败信号，不是进展。

### 另一个坑：参考图带来的东西

参考图里他肩上有一片叶子，生成出来**每一版肩上都带叶子**。

**参考图会把它身上的所有细节一起带过来。**

## 档案五：坐下喘 · 抽了 2 版

### 要拍什么

他扫到一半停下，坐到石沿上喘。

### 两版的错

| 版本 | 错在哪 | 原因 |
|---|---|---|
| v1 | **4 秒里塞了四个动作**（停下→放帚→坐下→喘），每件都做不好 | 一镜四动作 |
| v2 | ✅ 通过 | 砍成"只坐着喘"，动作交给剪辑补 |

### 关键认知

**"盘腿坐"在 AI 那里几乎等于"打坐"。**

写"盘腿坐下喘气"，它画出背直、端坐、手结印——**完全不像累垮了**。

**修饰语压不过默认值。**

### 解法

**不给它"盘腿"这个选项：**

```
他**不是盘腿、不是打坐**。
坐法是累极了的那种：一条腿曲着、另一条腿垂在沿外；
上身向前弯下去，肩膀垮着，头低着看地面；
右手撑在身侧的石板上（不是搭在膝上、不是结印）。
```

**"手撑在石板上"这个动作，AI 不会误解成打坐。**

## 档案六：佛前礼佛 · 抽了 2 版

### 要拍什么

他坐在台基石沿，右手抬到胸前竖掌，闭眼；一片叶子飘落在他身上，他不拂。

### 两版的错

| 版本 | 错在哪 | 原因 |
|---|---|---|
| v1 | **叶子是枫叶，还很大**；**G 到 H 没有抬手的过渡** | 叶子只写"枯叶"没写形状；坐下那镜 手在膝上，礼佛那镜 手已竖掌，中间跳了 |
| v2 | 待验 | 已改：叶子写死形状与尺寸；礼佛那镜 内含抬手 |

### 关键认知

**① "枯叶"不够，要写形状。**

```
一片最普通的枯树叶：简单的椭圆形，边缘微卷，没有裂片、没有尖角、没有锯齿。
暗褐色，接近土色。约拇指指甲大小——不能比他的耳朵大。
```

**"没有裂片"是正向描述；写"不要枫叶"会画出枫叶。**

**② 动作的过渡不能用剪辑糊过去。**

上一镜手在膝上，下一镜手在胸前——**中间必须有一个抬手**。

"观众会自己补"是错的：**那是一次真实的肢体变化，不拍就是跳帧。**

### 连带发现

**礼佛那镜 的构图被裁了，竹帚消失。**

首帧是全景（有竹帚），成片是中景（竹帚没了）。

**原因**：`不裁切` 那句写在 @图1 的说明里，位置太靠后。

**修法**：把构图锁放到提示词最前面，并给一个取舍优先级：

```
【构图锁定，先于一切】
这一镜的取景、景别、机位与原图完全一致。
如果必须取舍，**宁可人小一点，也要保住竹帚和台基石沿**。
```

## 档案七：素材被压缩（通用）

### 现象

归档的"定稿图"只有 320 KB，而原图是 3 MB。

### 原因

**图经过对话界面会被重新编码。** 任何从聊天里存下来的图，都是压缩版。

### 检查方法

```
PNG 且 < 1 MB   → 多半是压缩过的，不要用
```

### 铁律

**归档前先看文件大小。** 原图放在项目目录里，不要从聊天记录里另存。

## 档案八：色值误判（通用）

### 现象

同一件僧袍，在定妆照里测出 `#908C8D`（浅灰），在一张环境图里测出 `#444B49`（深灰绿）。

### 判断

**不是错，是光照衰减。**

浅灰的布在暗环境里当然读成深灰绿。

### 铁律

**定妆照是色值基准，环境图不是。**

不要因为环境图里颜色深了，就去"修"定妆照。

## 从八份档案里提炼的六条

```
① 首帧声明写「完整继承构图」，不写「不继承」
② 画面逐层列出，标明「缺一不可」
③ 动的东西必须在画面里有位置
④ 不写「推」，推在后期做
⑤ 一镜一个动作；动作复杂就拆镜
⑥ 参考图会把它身上的一切带过来——包括你不想要的
```
