# 负面词纪律：分配，不要禁止

**你写下的词，就是你召唤的东西。**

这一条推翻了很多人的直觉——**负面清单越长，画面越容易出那个错**。

---

## 一、核心：分配，不要禁止

### 错

```
❌ 画面不许发黄
❌ 不要暖色调
```

### 对

```
✅ 主色必须是冷的青绿。黄只存在于灯罩里，和灯下掌大的一圈光晕。
   如果画面变黄，画面就是错的。
```

**它不禁止黄色，它"分配"黄色**——一个具名来源（灯罩）+ 一个说明的尺寸（掌大的一圈）+ 一个模型能自查的判据（如果变黄，就是错的）。

### 为什么这样更有效

| 写法 | AI 收到什么 |
|---|---|
| "不许发黄" | "黄"这个词 + 一个模糊的否定 |
| "黄只在灯罩和灯下掌大一圈" | 黄的**位置**和**范围**，以及"其他地方没有黄"这个事实 |

**否定词在生成模型里的作用很弱**，因为它的训练目标是"生成符合描述的图"，而描述里出现了"黄"。

## 二、一个测试，不是一张清单

每写一个负面词，问自己：

> **模型的默认行为本来就是那个错吗？**

| 情况 | 做法 | 例子 |
|---|---|---|
| **是**（它本来就会那么错） | 可以简短禁止，**写在肯定句之后** | 扫地时爱加慢动作；打斗时爱加血浆；视频默认带 BGM |
| **不是**（ban 会把词喂给它） | **必须改成正面陈述** | 见下面的真实翻车 |

### 通过测试的合法 ban（7 类）

```
① 锁尾：写在肯定句末尾的短句
   "光线一致，不闪烁" / "写实照片级——不是 3D 渲染"

② 慢动作（打斗）
   模型自己就会加

③ 配乐
   生成的视频默认垫一层床。ban 本身是对的

④ 重复的人/物
   模型爱复制。用数量开头："画面里只有一个男人"

⑤ 复制参考音频的音色
   给一段音频做参考时，它会连音色一起借走

⑥ 参考图里想丢掉的东西
   写在后面，且要说明"我们这部片子里它是关着的"

⑦ 资产阶段的问题
   在图稿阶段禁掉，之后就别再提
```

### 不通过测试的（必须改成正面）

```
✗ 参考图漏出来的颜色     "不许黄" → 分配它
✗ 你不要的美术风格       "不要卡通" → 说清是什么
✗ 已经烘进素材的光学词   镜头定了就别再提
✗ 任何独立的负面清单     拆开，逐条判断
```

## 三、真实翻车档案

### 案例一：四个位置，四个选项

某镜要"一片叶子飘落在他身上"。禁止项写了：

```
禁止：叶子落在头顶、叶子落在左袖上、叶子落在肩上、叶子落在脸上
```

**这四句话把四个位置全给了 AI。**

结果：叶子落在了头顶。

**正确写法只有一句：**

```
落在他身上——衣襟上、膝上、或右袖上都可以，位置不必精确，自然就好。
```

### 案例二：一长串否定，反而激活

要让画面"没有音乐"：

```
❌ 必须没有：配乐、背景音乐、旋律、节拍、鼓点、和声、乐器、人声哼唱
```

结果：**生成出来带配乐。**

**「无BGM」是整体概念，模型认得准；"无旋律、无节拍"是把它拆开喂过去，反而激活。**

正确写法：

```
✅ 无旁白、无人物配音、无BGM。
```

### 案例三：禁止"枫叶"，画出枫叶

某镜要"一片普通的枯叶"，禁止项写了：

```
禁止：枫叶、银杏叶、红色叶子、金黄色叶子
```

结果：**画了一片枫叶。**

**正确写法：只写正向。**

```
一片最普通的枯树叶：简单的椭圆形，边缘微卷，轮廓规整，
没有裂片、没有尖角、没有锯齿。暗褐色，接近土色。
约拇指指甲大小，在画面里只占一点点——不能比他的耳朵大。
```

**"没有裂片"是正向的结构描述，"不是枫叶"是给它一个选项。**

## 四、判断口诀

```
模型本来就会犯的错   → 可以写一句短的 ban
模型本来不会犯的错   → 绝对不能提那个词
```

**写一个负面词之前，先问：我不说，它会主动这么干吗？**

- 会 → 写，短，放在肯定句后面
- 不会 → 删掉，改成正面描述

## 五、可以用的负面清单（已通过测试）

### 画风类（17 条）

```
避免：鲜艳糖果色、通体碧绿色偏色、肤色发青、粉紫色调、均匀正面补光、脸部美颜磨皮、
蜡质皮肤、塑料衣物、崭新洁净的古装、游戏建模质感、卡通渲染、过度锐化、全局泛光、
暗部完全死黑、亮部大面积过曝、跨镜头色温和饱和度跳变。
```

**每一条都是模型的默认倾向**：它默认会磨皮、默认会锐化、默认会把暗部压死、默认会让颜色跳。

### 音频类（3 条）

```
无旁白、无人物配音、无BGM。
```

有台词的镜：

```
无旁白、无BGM。
```

### 技术类

```
不裁切、不放大、不重新构图
不得推近、不得拉远
```

这三条针对的是"图生视频会自己移动机位"这个默认行为。

## 六、检查表

```
□ 每一个负面词，都通过"模型本来就会这么错吗"这个测试了吗？
□ 有没有提到画面里不存在的东西？（提了就是喂选项）
□ 有没有用"不是A、不是B、不是C"这种结构？（有就改成正面陈述）
□ 负面词都在肯定句后面吗？
□ 音频只有三无，没有拆成六七个词吧？
```
