# 表演与眼睛

**死眼是 AI 表演的第一号破绽。**

核心洞察：**死眼不是靠打光修的，是靠给眼睛一个任务。**

一个眼神发直但眼里有漂亮眼神光的人，还是眼神发直。

---

## 一、眼睛要有任务

### 错误做法

```
❌ 他眼神深邃
❌ 他目光坚定
❌ 眼里有光
```

这些都是**状态词**，不是**动作**。AI 收到状态词，画出一个"看起来深邃"的静止眼睛——那就是死眼。

### 正确做法

**眼睛在"做一件事"**，而且有明确的对象：

```
✅ 他盯着对方的两只眼睛，在找一个信任的闪光
✅ 每说完一点，他登记一下有没有说进去
✅ 他偷看一眼，在被发现之前收回来
✅ 他在衡量对方——把自己感受到的和对方表现出来的对照
```

**眼动的过程就是在"做"。** 活着 = 脑子在任务上逐刻运转。

### 四条具体

| 条 | 怎么写 |
|---|---|
| **微颤与注视** | 眼睛盯着他正在注意的东西；目光一直在动——飘开、想事时移开、扫到一个细节再落回来。**绝不锁死不动。** |
| **眨眼的节奏和质量** | 紧张时连眨；控制局面时慢而沉稳的眼皮；走神的瞬间"一眨一失焦" |
| **眼神光只让任务被看见** | 眼神光是渲染属性，不是解药 |
| **眼先动，头后动** | 眼睛比头先到目标；话没出口之前，眼睛里已有那个念头 |

## 二、静镜的低成本技巧

**一段三拍眨眼，在静态镜头里买一张活脸：**

```
一次懒眨眼 → 一次快速双眨 → 一次重的重置眨眼
```

### 但古装片的"静"是另一种

| 状态 | 不能写 | 要写 |
|---|---|---|
| **垂目**（佛像、僧人） | "完全静止，不眨眼" → 死脸 | "眼睛半睁向下，眼皮极缓地松了一下" |
| **闭眼**（礼佛、就义） | "闭着眼" → 像截断 | "闭眼之前有一次极轻的吸气，眼皮慢慢合上" |
| **不怒而威** | "瞪着眼不眨" → 像抽搐 | "眨得更少、更慢、更有决定；目光仍缓慢移动" |

**关键：静不是不动，是动得极慢且有意。**

## 三、把表演写进提示词的格式

不要写"他很难过"，要写**身体在做什么**。

```
【表演 · 只写这几样】
- 眼睛：<任务 + 对象 + 移动方式>
- 呼吸：<节奏 + 起伏位置>
- 肩背：<塌/直/前倾>
- 手：<在哪、做什么、还是不动>
- 脸：<不是表情，是脸的哪一部分在动>
```

### 例子：一个人刚干完重活坐下

```
❌ 他坐下来，显得很累

✅ 他坐在台基石沿上，背微微塌下去，**胸口明显起伏**——
   一口气吸进去、吐出来，肩膀跟着起落。
   右手搭在膝上，不动。眼睛睁着，看着前方地面，没有焦点。
```

### 例子：一个人在佛前垂目

```
❌ 佛像慈悲地垂目

✅ 眼睛半睁向下，瞳孔几乎看不见；不眨、不动。
   但眼皮极缓地松了一下——不是眨眼，是眼皮失去了一点点张力。
   面部的肌肉完全不动，只有那一下。
```

---

## 四、身体的三条

### ① 呼吸是最便宜的生命迹象

**胸口起伏 + 肩膀起落**，两句话，比任何"他很累"都有效。

写清**节奏**：一次呼吸几秒。

```
一口气吸进去、吐出来，用掉约三秒
```

### ② 重心决定真假

```
❌ 他站着
✅ 两脚分开、重心略偏前，上身微微前倾——这是干活的人站着的样子
```

**"重心略偏前"这五个字，比"站得很自然"有用十倍。**

### ③ 手最难

**手是 AI 最容易崩的地方。** 判断标准：

| 情况 | 做法 |
|---|---|
| 手只需要"在某个位置"（搭在膝上、垂着） | ✅ 可以写 |
| 手要做复杂动作（握持、操作工具） | ⚠️ 极高风险，考虑拆镜或改成不拍手 |
| 需要看清手指的关系（握法、姿势） | ❌ 基本做不对，改构图 |

**如果一镜反复崩在手部，不要再加约束——换构图，不拍手。**

## 五、台词的表演

**台词是同期声，人物本人发出，声画同步，有口型。**

所以台词行的写法要包含三件事：

```
<谁>（<画面里的位置 + 音色 + 语气>）开口说话——
**他本人发出的声音，声画同步**：嘴与下颌随字句动作，
声音从画面内那个位置来，音色与这个人相符。
不是画外有人念：「<台词>」
```

### 音色怎么写

```
✅ 中年男声，压着嗓子，带笑意
✅ 低、平、短，没有任何语气起伏
✅ 年轻女声，气不足，末尾掉下去
❌ 声音很有磁性
❌ 标准普通话
```

### 一个陷阱：说话的人看不见嘴

**如果说话的人不在画面里、不在光里、嘴被挡住，模型只能给画外音。**

四种要改构图的情况：

| 问题 | 改法 |
|---|---|
| 说话人在画外 | 让他入画 |
| 说话人是背影 | 侧脸抬起 |
| 说话人在暗里看不清嘴 | 给他的脸一点光 |
| 说话人被前景挡住 | 从侧面进画 |

---

## 六、眼睛的三条速查

```
□ 这一镜的眼睛在"做什么"？写了吗？
□ 如果是"不动"，有没有写"极缓地松一下"之类的微动？
□ 台词镜：说话人的嘴在画面里看得见吗？
```
