# 画风锁：七段式

一段固定文字，**逐镜照抄，不做任何缩写**。这是全片视觉一致性的唯一保障。

---

## 完整文本

```
画风锁：中国古装武侠电影的写实影像，宋代。整体气质苍凉、沉郁、厚重。
色彩：以青绿灰、墨绿青、炭黑为主色，土褐只用于木案、土地与器物；整体饱和度克制，
      保留肌肤的棕褐与微弱血色；环境和阴影轻微偏青绿，受光部位呈柔和暖金或琥珀色，
      冷暖分离清晰，暖色只集中在人物受光边缘与实际光源附近。
光照：低调，明确的侧光或侧逆光，大面积深色阴影，人物面部有自然的明暗分区；
      黑位深沉但保留衣物、头发和建筑的层次；亮部平滑过渡，窗光、灯火、日光有光源亮度、
      周围材质仍能辨认；近景厚重清晰，远景随距离降低对比度。
空气：薄雾、浮尘或湿气（按场景需要，不是每个场景都有雾）。
材质：人物皮肤保留毛孔、细纹、汗水、尘土与轻微瑕疵；衣物呈粗布、麻布质感，有磨损和褶皱；
      建筑呈现风化木纹、斑驳墙面和湿润石材，金属表面有氧化与使用痕迹；反光随材质变化，
      整体粗粝、真实。
镜头：35 毫米电影摄影的观感，人物镜头用自然透视与适度浅景深、环境仍可辨认；
      全景保留空间纵深；细微胶片颗粒，细节清晰且锐度自然，运动时保留合理的运动模糊；
      16:9 横画幅。
一致：与全片其他镜头使用同一套底色、材质与色温；肤色与衣物颜色跨镜稳定。
```

## 七段各自防什么

| 段 | 文字 | 防的错误 |
|---|---|---|
| **画风锁** | 古装武侠电影的写实影像 / 苍凉沉郁厚重 | 画面"干净利落的暗"——对，但没有旧味 |
| **色彩** | 冷暖分工，暖在受光边缘 | 整张泛绿 / 整张灰白 |
| **光照** | 黑位保留层次、亮部平滑、光源有亮度 | 背景被压成纯黑；光斑烧成白块 |
| **光照** | 近景厚重、远景降对比 | 整张图一起虚掉 |
| **空气** | 薄雾/浮尘/湿气 | 干净得像摄影棚 |
| **材质** | 毛孔/汗光/粗麻/风化木纹/金属氧化 | 蜡质皮肤、塑料感 |
| **镜头** | 浅景深但环境可辨 | 虚得太狠，或干脆不虚 |
| **一致** | 跨镜头同一底色与色温 | 剪起来一冷一热 |

### 最容易被忽略的两句

**「黑位深沉但保留衣物、头发和建筑的层次」**——不写这句，AI 会把背景压成纯黑。真实后果：一个佛像特写，背景全黑，佛像像浮在空中。

**「远景随距离降低对比度」**——不写这句，AI 会把整张图一起虚掉，或者一起清晰。真实后果：一片叶子的镜头，背景的石板虚成白幕，看不出是石头。

## 两型：有暖源 / 无暖源

**同一部片子里，这两型要分开。** 不是所有场景都该有暖光。

### A 型 · 有暖源

适用于：酒肆、灵堂、宅院、街市、战场（有火把/日光）

```
色彩：以青绿灰、墨绿青、炭黑为主色，土褐只用于木案、土地与器物；整体饱和度克制，
      保留肌肤的棕褐与微弱血色；环境和阴影轻微偏青绿，受光部位呈柔和暖金或琥珀色，
      冷暖分离清晰，暖色只集中在人物受光边缘与实际光源附近。
光照：低调，明确的侧光或侧逆光，大面积深色阴影，人物面部有自然的明暗分区；
      黑位深沉但保留衣物、头发和建筑的层次；亮部平滑过渡，窗光、灯火、日光有光源亮度、
      周围材质仍能辨认；近景厚重清晰，远景随距离降低对比度。
```

### C 型 · 无暖源

适用于：寺院、荒野、刑场、清晨的空镜

```
色彩：以青绿灰、墨绿青、炭黑为主色，土褐只用于木案、石阶与器物；整体饱和度克制，
      保留肌肤的棕褐与微弱血色；环境和阴影轻微偏青绿，受光部位是湿的白与冷的灰、不是暖金——
      全场没有任何暖色光源，唯一的暖色只允许出现在佛像的旧金与器物上；冷暖分离清晰。
光照：低调，只用侧光、不用侧逆光（不许给人镶金边），大面积深色阴影，
      人物面部有自然的明暗分区；黑位深沉但保留衣物、头发和建筑的层次；
      亮部平滑过渡，窗光与日光有光源亮度、周围材质仍能辨认；近景厚重清晰，远景随距离降低对比度。
```

### 两个关键差别

| | A 型 | C 型 |
|---|---|---|
| 受光部位 | 柔和的**暗金或琥珀** | **湿的白与冷的灰**，不是暖金 |
| 侧逆光 | 可以 | **禁止**——会给人镶一圈暖边 |

**"零暖光"是一个设计，不是漏了打光。**

如果全片都加暖金，等于把"他活在一个没有暖意的世界里"这个设计废掉。

## 色彩术语纪律

**同一个颜色，全片只能有一种写法。** 写错一个字，AI 会给你另一个颜色。

```
✅ 墨绿青    （绿在前，青在后）
❌ 墨青绿
❌ 冷灰       → 用「灰白」或「湿的白」
❌ 湿冷的灰白 → 用「湿的白」
```

## 影调基准（可量化）

生成后的画面可以用数值核对：

| 指标 | 目标 | 怎么算 |
|---|---|---|
| 亮度 | **0.10–0.22** | 整帧平均亮度 |
| 暗部占比 | **50–65%** | 亮度 < 0.25 的像素比例 |
| 高光占比 | **≤6%** | 亮度 > 0.85 的像素比例 |
| 主色 | 墨绿青 50–70% | 色相落在青绿区间 |
| 暖色 | 全景 ≤25% / 特写 ≤50% | 色相落在暖区 |

**注意**：这是**五帧的聚合判断**，不是逐帧卡死。单帧超一点没关系，连续五帧都超就是跑偏了。

**480P 样片阶段不要卡这些数**——压缩会改变直方图。到 1080P 再核。

## 避讳项（17 条）

```
避免：鲜艳糖果色、通体碧绿色偏色、肤色发青、粉紫色调、均匀正面补光、脸部美颜磨皮、
蜡质皮肤、塑料衣物、崭新洁净的古装、游戏建模质感、卡通渲染、过度锐化、全局泛光、
暗部完全死黑、亮部大面积过曝、跨镜头色温和饱和度跳变。
```

这 17 条是**允许的负面清单**，因为它们都通过同一个测试（见 `05-负面词纪律.md`）：**模型的默认行为本来就是这些错**。写出来不增加选项。

## 不要加的东西

| 想加的 | 为什么不能加 |
|---|---|
| **ARRI Alexa 65** | 和已有的"35mm 胶片颗粒"是两个相反的渲染指令，会互相抵消 |
| **2.35:1 宽银幕** | 如果输出是 16:9，这句会让模型在画面里画黑边 |
| **电影感 / 高级感 / 大片感** | 空词，占位置，不产生任何约束 |
| **8K / 超清 / 极致细节** | 会导致过度锐化，和"粗粝"打架 |

**"不够电影"时，加胶片型号（柯达 Vision3 500T），不要加摄影机。**
