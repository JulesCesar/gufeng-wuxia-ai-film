# 运镜：摄影机是主角情绪的影子

**运动、镜头、时长，都由人物的情绪状态决定**——不是由"看起来够不够电影"决定。

最明显的 AI 破绽：**平静的场景配一个抖动的手持；愤怒的场景配一个平滑的推轨。** 动作对，但镜头是"无感"的。

---

## 一、六种情绪 → 六种运镜

| 情绪 | 运镜处方 |
|---|---|
| **怒 / 紧 / 绷着** | 手持呼吸感、抖、不稳——呼吸节奏断裂，两轴都有细微抽动，幅度小但**节奏不规则**。不要上稳定器 |
| **静 / 在控 / 有把握** | 手持呼吸感、**平滑**——呼吸匀速，幅度规律。稳定器轻一点，但**还是活的** |
| **悲 / 脆弱** | 手持、**慢、低**——呼吸频率更低，摄影机有轻微下沉，像摄影师自己也变重了 |
| **惊 / 被揭示击中** | **静止 + 极缓推**（或极缓拉）——揭示的那一瞬定死，之后 0.5–2 秒几乎不动 |
| **动作 / 打斗** | 60fps，180° 快门——干净的运动，运动模糊来自快门，不是来自慢速快门 |
| **最后的判决 / 终结** | **顶拍定格，0.3–0.5 秒**——正上方，时间停住，所有位置锁死 |
| **崩溃 / 需要空间** | **从近景缓拉成全景**——"别逼他"，给观众**距离**，不是遗弃 |

### 最后一条最有用

**"从近景缓拉成全景"** 是给"一个人终于撑不住"用的：

- 他哭、他缩起来、他说不出话 → **不要推近**（推近是逼他）
- **拉远**，让观众站开一点——**视觉上的距离 = 情感上的空间**

这是纪录片和剧情片共用的老手法，但 AI 提示词里几乎没人写。

## 二、一条镜内情绪变化的写法

同一镜里情绪从 A 变到 B，摄影机要**同步变**。写成三段：

```
开段：按进入的情绪给运镜
过渡：摄影机怎么变（手持幅度减小、漂移收住、推进变慢）
收段：按离开的情绪给运镜
```

**摄影机跟着演员走，不按自己的时钟走。**

### 例子：怒 → 控

```
0–2 秒：手持，呼吸粗，两轴有明显的细微抽动，幅度小但节奏乱；
2–4 秒：抽动幅度一点点收住，呼吸变匀，像他自己把气压下去；
4–6 秒：完全稳下来，只剩匀速的呼吸感——他控制住了。
```

## 三、硬规矩三条

### ① 一镜只给一个主运镜

**叠两个以上（推 + 摇 + 抬）= 抖动、乱转、生成失败的第一原因。**

如果确实要两个，**必须写成有先后的两段，并给时间**：

```
❌ 摄影机推近并左摇
✅ 0–3 秒摄影机在原地向左摇，跟着他走到画面中间；
   4–8 秒，摇停，开始向他推近
```

### ② 微动要写精确距离

**给物理量，不给百分比。**

```
❌ 镜头极缓推进 3%
✅ 整 7 秒里，摄影机只后退 10–15 厘米——慢到几乎察觉不到。
   不要 zoom、不要突然推。
```

**为什么百分比无效**：模型不知道 3% 是相对什么。写"厘米/秒"它才有物理依据。

**而且要写明"不要 zoom"**——因为"推"这个字会被它理解成变焦，不是移动。

### ③ 反向检查：说的动作，能不能产生说的落幅

| 动作 | 能到的落幅 |
|---|---|
| 一个缓推 | 中景 → 近景，**到不了**大特写 |
| 10 厘米的后拉 | 近景 → 近景，**到不了**全身 |
| 一米的后拉 | 近景 → 中景 |
| 三米的后拉 | 中景 → 全景 |

**动作和落幅不一致时，模型会选一个、编另一个。**

修法：**要更大的移动，或者缩小落幅变化**——哪边便宜改哪边。

## 四、写真动作，不写 preset 名

**Higgsfield 里的 `Dolly In`、`Crash Zoom`、`Lazy Susan` 是平台的下拉选项。**

换成别的平台（LibTV / 可灵 / 即梦），这些名字不存在，要写成**动作描述**：

| preset 名 | 写成动作 |
|---|---|
| Dolly In | 摄影机沿地面向前移动，靠近主体 |
| Dolly Out | 摄影机向后退，主体在画面里变小 |
| Crash Zoom In | 镜头急速变焦推到某处（**这是变焦，不是移动**） |
| Crane Up | 摄影机从地面升高 |
| Arc | 摄影机绕主体做半圆移动 |
| 360 Orbit | 摄影机绕主体一整圈 |
| Handheld | 手持，有呼吸感的轻微晃动 |

### 移动 vs 变焦：必须分清

```
移动（dolly / track）  摄影机真的走过去 → 透视会变，前景后景关系会变
变焦（zoom）          摄影机不动，焦距变 → 透视不变，像裁切放大
```

**"推"这个词有歧义，两个都要防。**

---

## 五、静镜为什么不该"完全不动"

**"摄影机完全不动"在电影里几乎不存在。**

哪怕三脚架上，也有：

- 呼吸感（极轻的上下）
- 镜头呼吸（对焦时的微变）
- 光的变化

**所以写"固定机位"时，最好加一句"极轻的呼吸感"**——否则出来像一张被拉伸的图。

```
✅ 固定机位，只有极轻的呼吸感——三脚架上的摄影机，不是冻结的画面。
```

## 六、什么时候该用哪种

| 想表达 | 用 |
|---|---|
| 他发现了什么 | 静止 → 极缓推 |
| 他被击垮了 | 从近景缓拉成全景 |
| 他要做决定 | 顶拍定格 0.3–0.5 秒 |
| 他在忍 | 手持但平滑（在控） |
| 他要炸了 | 手持、抖、节奏乱 |
| 他走了 | 后拉，或者不动让他出画 |
| 这是结局 | 顶拍，或者极缓拉远到空 |

## 七、检查表

```
□ 这一镜的情绪是什么？运镜和它对得上吗？
□ 只有一个主运镜吗？（两个就要写成有先后的两段）
□ 微动写了物理量（厘米/秒）吗？写了「不要 zoom」吗？
□ 说的动作，能产生说的落幅吗？
□ 写了「固定机位」的镜，加了「极轻的呼吸感」吗？
□ 用的是动作描述，不是 preset 名？
```
