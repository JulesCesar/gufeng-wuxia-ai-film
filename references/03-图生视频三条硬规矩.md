# 图生视频的三条硬规矩

**参考图就是首帧。** 这一条决定了下面三条全部内容。

---

## 规矩一：首帧声明写「完整继承构图」

### 错的写法

```
@图1 是场景参考：完整继承五尊佛的纵深排列、须弥座、密铺方格天花……不继承构图。
```

**「不继承构图」六个字，让 AI 自由取景了。**

### 真实后果

一镜要拍"殿内五尊佛，由近到远排开，前景有供桌"。写完上面那句之后，生成出来是：

**一尊佛的膝盖，和一段莲座。**

五尊没了，供桌没了，佛头没了。

### 对的写法

```
@图1 是**首帧**：完整继承它的构图、取景、机位、光位与色彩——五尊佛的纵深排列、
最近那尊在画面右侧、胁侍菩萨在佛与佛之间、密铺方格天花在顶部。
画面第一帧必须与原图完全一致，**不裁切、不放大、不重新构图**。
```

### 判断口诀

| 模式 | 参考图是什么 | 挂载声明怎么写 |
|---|---|---|
| **图生视频** | **首帧** | 完整继承构图、取景、机位 |
| **全能参考** | 素材 | 只继承内容，不继承构图 |
| **文生视频** | 无 | — |

**「不继承构图」只对全能参考成立。用在图生视频上，就是叫 AI 自己取景。**

---

## 规矩二：把画面逐层列出来，标明「缺一不可」

### 现象

首帧里有供桌，生成出来供桌没了。

**而且构图是对的**——不是被裁掉，是 AI 主动把它去掉了。

### 原因

**AI 默认会丢掉「非主体」的前景。**

它认为"五尊佛"是主体，"供桌"只是环境，所以优先保主体、牺牲前景。

### 那个被丢掉的供桌有多重要

```
供桌：铺旧白布的桌子，桌面上有铜香炉、花瓶、烛台。
位置：画面下方约三分之一。
作用：**桌面高度只到佛像的膝盖**——它是佛像尺度的参照。
```

**没有供桌，五尊佛就只是五个塑像。** 有了供桌，观众才知道那佛有多大。

### 写法

```
【画面必须有这四层，缺一不可】
① 前景（画面下方约三分之一）：铺着旧白布的供桌，桌面上有铜香炉、花瓶、供品、两只烛台。
   这张桌子是佛像尺度的参照——**桌面的高度只到佛像的膝盖**。它必须一直在画面里。
② 中景：五尊佛沿纵深排列，最近那尊在画面右侧；多层雕饰的须弥座；胁侍菩萨立在佛与佛之间。
③ 背景：密铺方格天花压顶，深褐的梁架与圆柱。
④ 左侧：一道冷光从高窗斜切下来，穿过空气，落到最近那尊的膝上。
```

### 「缺一不可」这四个字必须写

不写这四个字，AI 会自己决定丢哪一层。

## 规矩三：动的东西必须「本来就在画面里」

### 现象

提示词写"香火的烟在缓慢上升"，生成出来**一整片雾**，淹了半个画面。

### 原因

**画面里没有香炉。**

AI 要画"烟"，但它找不到烟从哪来——于是造了一整片雾，铺满整个空间。

### 因果顺序错了

```
我写的顺序：  烟在飘            → AI：烟在哪？造一个
正确的顺序：  供桌在 → 桌上有香炉 → 香炉上有一丝极薄的烟
```

### 写法

```
【画面必须有这四层，缺一不可】
① 前景：铺旧白布的供桌，桌面上有铜香炉……
（其余三层）
动作：**只有供桌上那只铜香炉的香火，升起一丝极薄的烟**——
      烟几乎是透明的，只在左侧那道光里露出一线轮廓，其余看不见；
      上升极慢，没有边界，不成股。
      **不要新增雾、不要把雾加厚、不要干冰、不要舞台烟雾。**
```

### 通用规则

**提示词提到的每一样东西，都得在画面里有位置。没有位置，AI 会自己编一个。**

| 想说 | 先说 |
|---|---|
| 落叶 | 画面里有树 |
| 握刀 | 画面里有手 |
| 灰尘在光里 | 画面里有一道光 |
| 马在跑 | 画面里有马 |

## 附：不要在提示词里写「推镜」

### 现象

写"镜头极缓推进 3%"，生成出来**推了 15–20%**，主体被推出画外。

### 原因

**AI 分不清「极缓」和「推」。** 只要出现"推"这个字，它就往明显了做。

### 做法

提示词一律写 **「静止机位」**。需要推的，**后期做**：

```bash
ffmpeg -i in.mp4 -vf "zoompan=z='min(zoom+0.00005,1.02)':d=1:x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':s=1920x1080" -c:a copy out.mp4
```

后期推 2% 就是 2%，不会推过头。

### 如果要"活"但不想动

**"完全不动的镜头"可以靠别的东西活**：

```
动态：只有这一件，别的不许动——
光切开的空气里，有一两点极细的浮尘在缓慢飘移，硬的颗粒，一两粒，几乎看不出。
不是烟、不是雾、不成片。
镜头静止机位，一帧都不推、不拉、不摇。
```

**浮尘是硬的颗粒，不会成片；烟和雾会成片。**

---

## 三条规矩的检查表

生成前逐项打勾：

```
□ 首帧声明写的是「完整继承构图」，不是「不继承」
□ 画面分了几层？每层都写了吗？写了「缺一不可」吗？
□ 要动的东西，在画面里有位置吗？
□ 有没有写「推」「拉」「摇」？有就删掉
□ 禁止项里有没有提到画面里不存在的东西？（有就是喂选项）
```
